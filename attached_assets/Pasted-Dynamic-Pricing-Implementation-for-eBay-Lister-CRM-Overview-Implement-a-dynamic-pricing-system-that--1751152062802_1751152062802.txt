Dynamic Pricing Implementation for eBay Lister CRM
Overview
Implement a dynamic pricing system that automatically calculates selling prices based on supplier cost with tiered margin percentages.
Pricing Tiers Structure
Tier 1: €1.00 - €5.00

Margin: 500%
Formula: Supplier Price × 6.00
Example: €3.00 → €18.00

Tier 2: €5.01 - €9.99

Margin: 300%
Formula: Supplier Price × 4.00
Example: €7.50 → €30.00

Tier 3: €10.00 - €15.00

Margin: 200%
Formula: Supplier Price × 3.00
Example: €12.00 → €36.00

Tier 4: €15.01 - €25.00

Margin: 150%
Formula: Supplier Price × 2.50
Example: €20.00 → €50.00

Tier 5: €25.01 - €50.00

Margin: 100%
Formula: Supplier Price × 2.00
Example: €35.00 → €70.00

Tier 6: €50.01 - €100.00

Margin: 75%
Formula: Supplier Price × 1.75
Example: €75.00 → €131.25

Tier 7: €100.01+

Margin: 50%
Formula: Supplier Price × 1.50
Example: €150.00 → €225.00

3. User Interface Components

Bulk Price Update: Button to recalculate all product prices
Individual Price Override: Allow manual price adjustments
Pricing Preview: Show before/after prices when importing products
Margin Display: Show applied margin percentage in product list
Price History: Track price changes over time

4. Business Logic Features

Minimum Price Floor: Set absolute minimum selling price (e.g., €2.00)
Maximum Price Ceiling: Cap prices at reasonable levels
Rounding Rules: Round to nearest €0.05 or €0.99 endings
Competitive Pricing: Optional integration with eBay price comparison
Seasonal Adjustments: Ability to apply temporary margin multipliers

5. Automation Features

Auto-update on Import: Calculate prices when importing supplier catalogs
Scheduled Repricing: Daily/weekly price updates based on supplier changes
Price Change Notifications: Alert when prices change significantly
Batch Processing: Handle large product catalogs efficiently
